## Installation

### Prerequisites

- [Node.js](https://nodejs.org/) >= 16
- [npm](https://www.npmjs.com/) >= 8

### Steps

1. **Clone the repository** :
```bash
git clone git@github.com:za-itOrg/webmail-front.git 
```
2. **Navigate into the project folder** :
```bash
cd webmail-front
```
3. **Install dependencies** :
```bash
npm install
```
4. **Run the project** :
```bash
npm run dev
```
5. **Open the app in your browser (default url)** :
```bash
http://localhost:5173
```
